# XroHub

A premium video streaming platform inspired by YouTube.

**Version:** 2.0.0 (UI overhaul — single-file design)

## Structure
- `index.html`: Complete app in one file (markup, styles, logic).

## Features
- Dark glassmorphism header with backdrop blur
- Righteous logo + Poppins typography
- Search videos by title or channel
- Category filters (chips + sidebar): All / Coding / Music / Gaming / Live / Vlogs
- Responsive sidebar: mini-sidebar with labels on desktop, drawer + backdrop on mobile
- Player modal with play/pause, progress bar with live time, Space key toggle
- Like / Share buttons, live badge with pulse animation
- Accessible: skip link, focus states, keyboard navigation, aria labels
- `prefers-reduced-motion` support
- Lazy-loaded thumbnails, animated toast notifications

## Tech Stack
- HTML5
- Tailwind CSS (via CDN)
- Google Material Icons
- Vanilla JavaScript
