# XroHub

A video sharing platform inspired by YouTube.

**Version:** 1.0.0 (major redesign)

## Structure
- `index.html`: Main page layout.
- `style.css`: Custom styles, scrollbar overrides, focus states.
- `app.js`: Video rendering, search, filtering, sidebar, player modal.

## Features
- Dark OLED theme with Righteous + Poppins typography
- Search videos by title or channel
- Category tag filtering (All / Music / Gaming / Live / News / Coding / Vlogs)
- Responsive sidebar: collapsible mini-sidebar on desktop, drawer on mobile
- Video player modal with play/pause and progress
- Accessible: skip link, visible focus states, keyboard navigation, aria labels
- `prefers-reduced-motion` support
- Lazy-loaded thumbnails

## Tech Stack
- HTML5
- Tailwind CSS (via CDN)
- Google Material Icons
- Vanilla JavaScript
